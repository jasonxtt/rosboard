# rosboard UX 标准 · Aurora 玻璃拟态

> 本文件是 **feat/ui-rebuild 分支专属**的前端 UX 标准，仅随本分支存在；不写入项目级
> `AGENTS.md`，不影响其他分支。任何在本分支上编写/修改前端代码的人（或 agent）都必须遵守。
>
> 风格来源：`design/mocks/05-aurora.html`（用户评审选定）。若本文件与 mock 冲突，以本文件为准。

---

## 1. 产品定位与设计原则

rosboard 是局域网部署的 RouterOS 监控面板：多设备、只读监控 + 策略配置（策略路由 / 访问控制 / 目标库）。
UI 设计按优先级遵循：

1. **监控一眼可读** — 进入任何页面 3 秒内能回答「现在正常吗」。关键指标用大数字，状态用色彩 + 文字双重编码。
2. **设置一步到位** — 策略概念用「谁 → 访问什么 → 走哪条线路」的流向语言表达，不让用户理解 RouterOS 内部对象。
3. **玻璃质感，克制使用** — 毛玻璃卡片是签名材质，但不牺牲可读性与性能（见 §3）。
4. **中文优先** — 全部界面文案为简体中文；术语统一见 §13。
5. **明暗双主题** — 深色为默认主题（Aurora 完整形态），浅色为等价变体（同一套 token，玻璃质感减弱、阴影增强）。

非目标：不做营销页式动效；不堆砌渐变文字；不以美观为由降低信息密度到「看不懂状态」的程度。

## 2. 色彩系统

所有颜色必须通过 CSS 变量引用，组件内禁止写死色值。变量定义在 `web/src/styles/tokens.css`，
按 `[data-theme="dark"]` / `[data-theme="light"]` 切换。

### 2.3 语义色（两主题通用，浅色下文字色加深一档）

| Token | 深色值 | 用途 |
| --- | --- | --- |
| `--ok` / `--ok-soft` | `#6ee7b7` / `rgba(110,231,183,.14)` | 在线、已应用、成功 |
| `--warn` / `--warn-soft` | `#fcd34d` / `rgba(252,211,77,.13)` | 空闲、待应用、告警 |
| `--err` / `--err-soft` | `#fda4af` / `rgba(253,164,175,.13)` | 离线、失败、阻断 |
| `--accent` / `--accent-soft` | `#67e8f9` / `rgba(103,232,249,.12)` | 主强调（链接、激活态、流向终点） |
| `--accent-2` | `#c4b5fd` | 次强调（上传流量、IPv6、辅助系列） |
| `--grad-brand` | `linear-gradient(135deg,#818cf8,#22d3ee)` | 品牌渐变（logo、主按钮、图表主线） |
| `--grad-ok` | `linear-gradient(90deg,#34d399,#22d3ee)` | 开启态开关 |

状态表达规则：在线/运行=ok；空闲/待应用/降级=warn；离线/失败/拒绝=err；信息性=accent。
**颜色必须搭配文字或图标**，禁止仅靠红绿色传达含义。

## 3. 玻璃材质（签名卡片）

```css
.glass {
  background: var(--glass);
  border: 1px solid var(--stroke);
  border-radius: var(--r-lg);
  backdrop-filter: blur(18px);
  -webkit-backdrop-filter: blur(18px);
  box-shadow: var(--shadow-card);
}
```

- `backdrop-filter` 只允许出现在**视口内常驻的少数容器**（顶栏、hero 卡）。长列表/表格的行项
  不使用 backdrop-filter，改用 `background: var(--glass-2)` 实色近似，避免滚动掉帧。
- 浅色主题下 `blur(10px)`，主要靠阴影分层。
- 悬停可交互卡片：`transform: translateY(-2px)` + `background: var(--glass-2)`，150ms。
- `prefers-reduced-motion: reduce` 时关闭所有过渡动画。

## 4. 字体与数字

- 字体栈：`-apple-system, "SF Pro Rounded", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
  等宽数字场景（IP、速率、时间戳）：`font-variant-numeric: tabular-nums`，不换字体族。
- 字阶：11(弱) / 12(辅助) / 13(正文) / 14(卡片标题) / 16(区标题) / 19(页标题) / 26(指标) / 44(hero 大数字)。
- 指标数字字重 700，页面标题 650，正文 400–500。
- 速率/流量一律用「数值 + 单位」两截式（`186.4` + `Mbps`），格式化函数统一在 `lib/format.ts`。

## 5. 布局与栅格

- 圆角：`--r-sm:10px / --r-md:14px / --r-lg:20px / --r-xl:24px`；卡片用 lg，hero 用 xl，按钮/输入用 md，徽章/药丸用 999。
- 间距 8pt 基准：4/8/12/16/20/26/32。
- 桌面内容最大宽度 1320px 居中；卡片间距 16px。
- 断点：`≥1200` 完整栅格；`768–1199` 两列；`<768` 单列 + 移动端导航（§11）。
- 页面骨架：顶部玻璃导航条（常驻）→ 页面区（`padding: 22px 26px 70px`）。

## 6. 导航与外壳

- **顶栏**（玻璃、常驻）：logo + `rosboard` | 中央药丸导航（概览/接口/终端/策略/更多…）| 设备药丸（绿点 + 设备名 + 状态）| 告警铃（带计数角标）| 主题切换 | 设置。
- 药丸导航：激活项 `background: var(--glass-2)`，圆角 999；项数超出时收进「更多」。
- 视图分组沿用现有信息架构：仪表台 / 系统概览 / 状态监控（接口·终端·流量·网络服务·系统运行）/
  主机设置（目标库·策略路由·访问控制·识别设置）/ 面板设置。监控子视图在页面内用二级药丸切换。
- **设备切换**：点击设备药丸弹出玻璃浮层，列出全部设备（在线点 + 名称 + 版本），另有「设备总览」入口；
  切换设备必须重置所有设备级页面状态。
- **告警**：铃铛弹出最近事件列表（级别色点 + 文案 + 相对时间），角标计数来自 dashboard `alerts`。
- 全局警告条：后端 `warnings` 非空时在顶栏下方显示琥珀色细条，可展开。

## 8. 图表规范（uPlot）

- 图表库：**uPlot**（~45KB）。ECharts 已从依赖移除。环形表/sparkline 用手写 SVG。
- 实时流量图：下载主线 `stroke: url(--grad-brand)` 宽 2.4 + 下方渐变面积（`#67e8f9` .30→0）；
  上传次线 `--accent-2` 宽 1.4 虚线或 70% 透明。网格线 `var(--stroke)` 虚线，只画横线。
- 坐标轴：文字 11px ink-3；时间轴按窗口自动（5m 窗口显示 `HH:MM:SS`，24h 显示 `HH:MM`）。
- 图例放卡片标题行右侧：色点 + `下载 186.4 Mbps` 实时值，不画悬浮 tooltip 框（hover 十字线 + 顶部读数即可）。
- 多窗口切换用药丸段控（5m/1h/6h/24h），切换不清空已有曲线，先显示旧数据再替换。
- 历史负载图（负载历史页）：每指标一张小图，线色依次为 accent / ok / accent-2 / warn / err。

## 9. 关键页面范式

### 9.1 系统概览（首页）
- Hero 玻璃大卡：状态行（呼吸绿点 + 「网络状态极佳/存在告警」+ 设备 + 运行时长）→
  **44px 下载大数字** → 一排小指标（上传 / 在线终端 / 活动连接 / 今日流量）→ 底部通栏实时流量图。
- 右侧卡：三环形表（CPU/内存/存储）+ 系统信息行（RouterOS 版本、平台、采集间隔、告警数）。
- 「活跃终端」网格卡（图标 + 名称 + IP/连接数 + 右侧速率），按速率排序，最多 8 个，更多进终端页。
- 「正在发生」事件卡（图标 + 一句人话 + 相对时间）。

### 9.2 策略路由 / 访问控制
- 出口卡横排：WAN 图标 + 名称 + 状态徽章 + kv 行（接口/协议族/故障策略/当前负载）。
- 分流规则与访问规则用**整宽规则表**（DataTable，遵守 §7 表格规范），一行一条规则，按优先级/名称排序；
  流向语义「来源 → 目标 → 出口/阻断」展开为相邻列，单元格内复用流向胶囊（flow-node 小胶囊，不画 → 箭头）。
  - 分流规则列：名称（次级行 12px ink-3「修订 N」）· 优先级（右对齐 tabular-nums）· 来源 · 目标（含规则数 cap）·
    出口（按协议族分行，IPv4 在上：接口模式显示「接口·网关」如 `xray·10.0.2.1`，点对点无 IP 只显示接口名，
    下一跳模式（wanSource=next-hop）无接口名、直接显示网关 IP；完整出口名 rb_ipv4_wan_… 放 Tooltip；无出口显示「出口缺失」）· 状态 · 启用 · 操作（✎/🗑）。
  - 访问规则列：名称（次级行「创建于 N 分钟前 · 修订 N」）· 来源（自动/固定/未解析 tag）· 目标 ·
    动作（`--err` 红胶囊「禁止互联网/阻断访问」）· 时段（「始终 · 全天阻断」/「周一至周五 20:00–22:00 · 阻断」）· 状态 · 启用 · 操作。
  - 状态徽章色彩 + 文字双编码；访问规则的 issues 并入状态 Tooltip，并在状态徽章下放 warn 色「问题」小徽章作可见指示。
- 「待应用」规则行：左侧 `--warn` 内描边 + `--warn-soft` 行底色 + 琥珀徽章 + 状态列下方「审查并应用 →」。
- 已停用规则行整体 opacity 0.62 降淡；规则行不可点击，编辑/删除只走操作列图标按钮（删除需确认弹窗）。
- 移动端（<768px）每张规则表最多保留 4 列：名称 / 目标 / 状态 / 操作，其余列以 col-hide-sm 隐藏，完整信息进编辑弹窗（§11）。
- 计划审查（Plan）弹窗：按 menu 分组的变更清单（create 绿 / patch 黄 / delete 红），
  blocker 红条、warning 琥珀条、需确认的 acknowledgement 复选框，应用后进入 job 进度条视图。

### 9.3 终端页与终端详情
- 终端页默认表格视图（密度优先），可切卡片网格；支持搜索、状态过滤、IPv4/IPv6 分域。
- 详情页顶部：设备图标 + 名称（可编辑 ✏）+ 状态点 + 关键地址 chips；下分「连接 / 流量分布 / 历史」药丸页签。

### 9.4 设置
- 左侧二级目录（玻璃卡内）+ 右侧内容区；危险操作（归档/清除数据/完全重置）统一放「危险区」红色描边卡内，
  需输入设备名或勾选确认。需要重启的保存操作：按钮变为「已保存，等待面板重启…」并自动轮询恢复。

## 10. 动效

- 统一 `transition: 150ms ease`；卡片 hover 位移 2px；弹窗 180ms 缩放 .97→1 + 淡入。
- 数字刷新不做滚动动画；状态变化用色点过渡。
- 呼吸点动画仅用于「在线/采集中」一处（hero 状态点），2.6s 循环。

## 11. 移动端（<768px）

- 顶栏收起为：logo + 页面标题 + 告警铃 + 汉堡；主导航变为底部药丸浮动条（最多 5 项 + 更多抽屉）。
- Hero 大数字降为 32px；指标卡两列；终端网格单列；表格保留 4 列以内，其余进详情。
- 触控目标 ≥40px；弹窗变底部抽屉（圆角 24px 顶、可下滑关闭）。
- `backdrop-filter` 在移动端只保留顶栏与底部导航。

## 12. 工程约束（与风格同等强制）

- 技术栈：React 19 + TypeScript + Vite（不换）；构建输出 `internal/ui/dist` 的链路不动。
- 依赖：新增仅允许 `uplot`；**echarts 已移除**，禁止重新引入；禁止再引入 UI 框架/CSS 框架。
- 样式方案：全局 CSS 变量 + 普通 CSS 文件（`styles/`），不引入 CSS-in-JS。
- 主题：`data-theme` 属性挂在 `<html>`，偏好存 `localStorage["rosboard:theme"]`，默认跟随系统深色。
- API 层：feature 内 `api.ts` 用 `safeObject/safeString/...` 守卫解析 `unknown`；组件不直接 fetch；
  禁止 `any`；设备作用域接口必须带 `?device=`；切换设备必须重置页面状态。
- 轮询：沿用后端心跳模型（viewer-heartbeat 保持快轮询），页面隐藏时停止轮询。
- 质量门：`npm --prefix web run lint` 与 `npm --prefix web run build` 必须全绿才算完成。
- 视觉验收由用户执行；交付时附「打开哪个 URL、看什么、预期是什么」的清单（遵守 frontend spec）。

## 13. 术语表（界面文案统一）

| 术语 | 含义 | 禁用说法 |
| --- | --- | --- |
| 出口 | 一条 WAN 线路 + 其路由/NAT/故障策略（Egress） | 出口节点、上游 |
| 分流规则 | 策略路由规则（谁 → 目标 → 出口） | 策略、路由策略混用 |
| 来源 | 规则作用的终端集合（全部/指定/排除） | 主体、Subject |
| 目标库 | 域名/IP 目标列表（TargetList） | 规则集、订阅 |
| 访问控制 | 阻断类规则（断网/屏蔽目标） | 防火墙、ACL |
| 协议族 | IPv4 / IPv6 | 地址族 |
| 已应用 / 待应用 / 应用中 / 失败 | 规则与 RouterOS 实际状态的关系 | 生效中（已应用除外） |
| 在线 / 空闲 / 离线 | 终端状态（≤5min 无流量=空闲） | 活跃、断开 |
