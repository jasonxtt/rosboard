Linear 极简

浅色单强调色键盘优先开发者工具感

对标 Linear / Vercel：几乎无装饰的细线界面、灰阶 + 单一紫色强调、⌘K 命令菜单与快捷键。优势是极致干净、表单与表格最高效，策略配置这类复杂操作的体验最好；监控大屏感较弱。

04

CRT 终端

深色荧光绿ASCII 图表极客玩具感
打开 ↗

致敬 htop / 终端美学：磷光绿、等宽字体、ASCII 折线图、F1/F2 功能键切换。优势是个性极强、与 RouterOS 极客气质契合；缺点是中文等宽渲染一般、移动端与复杂表单不友好，更适合作为「彩蛋主题」而非主界面。

Aurora 玻璃拟态

深色渐变毛玻璃大数字消费级亲和力
打开 ↗

对标 eero / Plume / Apple 家庭 App：极光渐变背景 + 毛玻璃卡片 + 大字号关键指标，策略规则用「谁 → 什么目标 → 哪条线路」流向图表达，是 5 个方案里策略概念最易懂的。密度最低，适合「好看 + 好用」优先、终端数量不爆炸的场景。
