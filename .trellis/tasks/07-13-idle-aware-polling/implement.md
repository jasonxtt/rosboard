# 实施计划

1. 为 Monitor 增加活动期限、状态转换和双调度器唤醒机制，并添加纯状态单元测试。
2. 重构实时与后台调度循环：活跃使用 1/3/10 秒，空闲仅使用 60 秒全量轮询。
3. 新增非阻塞 `POST /api/viewer-heartbeat`。
4. 前端增加可见页面心跳和恢复可见时立即心跳，保持现有刷新 UI。
5. 更新监控契约规范和嵌入式前端。
6. 验证空闲/唤醒节奏、Go tests/race、前端 lint/build/audit、浏览器控制台、本地及局域网 HTTP 200。

## Risk points

- 不能让每 10 秒续期都触发立即全量采集。
- 活跃期限到期时不得留下已经安排好的 1 秒/3 秒采集持续运行。
- 页面初始 dashboard 请求可能早于首次唤醒采集；后续实时请求必须自然获得新快照。
