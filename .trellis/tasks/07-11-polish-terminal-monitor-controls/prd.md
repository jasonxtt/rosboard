# Polish terminal monitor controls

## Goal

让终端监控默认聚焦在线设备，并统一工具栏和表格操作链接的视觉样式。

## Requirements

1. 全部终端、IPv4、IPv6 页面首次进入时只显示 `online` 终端。
2. 接口筛选旁增加“显示离线设备”按钮；点击后显示全部状态并改为“隐藏离线设备”，再次点击恢复仅在线。
3. 保留现有状态下拉框，用户仍可精确选择在线、空闲或离线；切换按钮与当前状态筛选保持一致。
4. 搜索框宽度缩短，并与相邻下拉框统一为 34px 高度。
5. 设备地址链接、详情和修改备注按钮不显示浏览器默认黑色边框。
6. 键盘焦点仍以协调的蓝色焦点环显示，不能通过彻底禁用焦点提示损害可访问性。
7. 完成后构建并重启 `0.0.0.0:8080`，局域网可访问。

## Acceptance Criteria

- [x] 首次打开终端监控时状态选择为“在线”，列表不包含空闲和离线行。
- [x] “显示离线设备”切换为全部状态，“隐藏离线设备”恢复仅在线。
- [x] 搜索框和下拉框高度一致，搜索框宽度不再明显大于筛选控件。
- [x] IP/MAC、详情、修改备注链接无黑色矩形边框，鼠标和键盘操作仍正常。
- [x] 前端 lint/build 和项目测试通过。
- [x] 浏览器实测交互与布局符合要求，8080 本机和 LAN 地址返回 HTTP 200。

## Out of Scope

- 改变后端在线、空闲、离线状态判定。
- 删除备注编辑能力或状态下拉筛选能力。
