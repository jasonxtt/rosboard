# 完善系统概览图表语义与悬浮详情

## Goal

在系统概览中统一四张资源卡片的即时状态表达与历史趋势交互：让在线终端和活动连接像 CPU、内存一样拥有简洁的横向比例概览，并让 CPU、内存、在线终端、活动连接四张折线图都能通过鼠标悬浮查看时间点详情，同时保持页面简约、不显繁琐。

## Background

- CPU 使用率和内存使用率当前除折线图外，还各有一条展示百分比的横线。
- 在线终端需要新增一条三分段横线，表达在线、近期未活跃和离线终端。
- 活动连接需要新增一条三分段横线，表达 TCP、UDP 和其他协议。
- 新增横线需要解释各分段语义，但不能挤占底部“平均 / 峰值”历史摘要。
- 实时流量图已有鼠标悬浮后显示时间和具体数值的交互，可作为四张概览折线图的体验参照。

## Requirements

- R1：在线终端卡片增加一个横向比例概览，完整表达在线、近期未活跃、离线三种状态；允许使用三段，避免把近期未活跃误称为离线或从总数中遗漏。
- R2：活动连接卡片增加一个三分段横向比例概览，表达 TCP、UDP 与其他协议的构成；三段合计必须等于当前活动连接总数。
- R3：在线终端和活动连接在卡片标题同行右侧显示只含名称与色点的极简图例；图例不重复数量，不新增纵向区域，底部“平均 / 峰值”保持不变。
- R4：鼠标悬浮比例横线的任一分段时，显示该分类的名称、当前数量与占比。
- R5：CPU、内存、在线终端、活动连接四张折线图支持鼠标悬浮详情，展示对应时间及该时间点的具体数值。
- R6：折线与分段横线的悬浮交互采用一致、轻量的深色浮层，并尽量复用实时流量图的视觉语言；每张图使用正确的指标名称和单位。
- R7：不改变系统概览原有的信息层级、卡片高度和紧凑布局。
- R8：将验证通过的 Linux amd64 嵌入式构建发布到 `10.0.0.6`，替换现有 `/opt/rosboard/rosboard`，保留可回滚备份并恢复 `rosboard.service` 健康运行。

## Technical Notes

- 四张卡片共用 `MetricCard` 和纯 SVG `MiniSparkline`；CPU/内存的横线由 `progress` 控制，在线终端与活动连接当前没有横线。
- `LoadSample` 已同时提供时间戳、CPU、内存、在线终端数和活动连接数，因此四张折线图的悬浮时间点详情不需要新增历史采样接口。
- 实时流量图使用 ECharts 的轴触发 tooltip；迷你折线当前为 `aria-hidden` 的原生 SVG。实现时应保持迷你图的轻量尺寸，并复用实时流量 tooltip 的视觉语言，而非直接复制其完整坐标轴。
- 当前 `DashboardResponse.terminals` 可区分 `online`、`inactive`、`offline` 三种状态；`inactive` 表示最近五分钟内失去强在线证据。产品决定使用三段横线完整表达这三类，不将其静默归入在线或离线。
- 当前 `connectionCount` 是全部活动连接总数；`protocols` 按应用分类聚合且同一分类只保留一个协议字段，不能可靠地直接推导全局 TCP/UDP 构成。精确协议横线应在后端直接按原始连接协议统计，保持现有协议统计页面契约不变。
- 产品决定活动连接使用 TCP、UDP、其他三段，使分段总数与活动连接总数一致。
- 产品决定将三项色点图例放在卡片标题同行右侧；底部继续只显示平均值与峰值。分段数量和占比按需在横线悬浮层中显示。

## Acceptance Criteria

- [x] 在线终端横线能直观表达在线、近期未活跃、离线三部分及其相对比例，三段合计等于当前已知终端总数，零值和总数为零时显示合理。
- [x] 活动连接横线能直观表达 TCP、UDP、其他协议三部分及其相对比例，三段合计等于当前活动连接总数，零值和总数为零时显示合理。
- [x] 两条新增横线在标题行通过三项色点图例说明语义；图例不显示重复数字，且不挤压或替换底部平均值与峰值。
- [x] 鼠标悬浮任一有效分段时显示分类名称、当前数量和占比；零宽分段无需构造不可操作的悬浮目标。
- [x] 四张概览折线图在鼠标悬浮有效数据点时显示时间和该图所有相关系列的具体数值与单位。
- [x] 悬浮层不会明显遮挡关键内容，离开图表后消失，并沿用项目已有图表交互风格。
- [x] 标题图例与分段横线具有可读的无障碍文本；不能仅依赖颜色传达分类。
- [x] 现有 CPU、内存、实时流量及概览布局行为不发生非预期回归。
- [x] `10.0.0.6` 上的旧程序、配置和 SQLite 数据已按同一时间戳备份，新程序替换后服务为 active，健康接口、Dashboard 新字段和嵌入式前端资源均可访问。

## Out of Scope

- 修改历史采样表或增加协议构成历史；本次只增加当前终端状态与当前连接协议构成字段。
- 重构系统概览之外的图表组件。
- 增加点击筛选、缩放、时间范围切换等新的分析功能。
