# 按参考图重塑系统概览

## Goal

以用户提供的参考图为硬性视觉基准，重新实现 Rosboard 系统概览，并把同一套导航、顶栏、卡片、表格和状态语言应用到现有监控页面，使实际浏览器效果在结构、密度、组件层级和视觉细节上明显接近参考图。

## Background

- 上一轮实现只完成了换色、响应式和部分模块整理，与已批准参考图存在明显偏差。
- 参考图明确展示：带图标的分组侧栏、紧凑全局顶栏、四张高信息指标卡、实时流量图、系统状态、接口状态和最近告警。
- 当前 API 已提供 CPU、内存、存储、在线终端、活动连接、流量历史、接口状态、RouterOS 信息和 warnings；没有稳定提供风扇、电源、温度或历史告警事件。
- 不允许为了匹配截图虚构监控值、历史趋势、告警时间或硬件能力。
- 用户已明确要求按参考图重塑，不再接受仅做配色近似的实现。

## Requirements

- 参考图是结构和视觉验收基准，而非仅供配色参考。
- 顶部只保留四张指标卡：CPU、内存、在线终端、活动连接；每张包含图标、主值和真实辅助信息。
- CPU、内存和在线终端迷你趋势只能来自 `/api/load` 的真实样本；活动连接无历史序列时使用真实协议/连接分布，不绘制虚假趋势。
- 首屏主体按参考图布局：左侧实时流量、右侧系统状态；下方左侧接口状态、右侧当前告警/健康事件。
- 系统状态使用真实字段替代参考图中当前设备不提供的温度、风扇和电源项目。
- 告警区由 `warnings`、接口离线/禁用、错误/丢包等当前事实产生；不得编造历史时间。
- 顶栏提供真实系统状态、更新时间、手动刷新和全局刷新周期选择。
- 侧栏为每个主要导航项提供同风格 SVG 图标，并在底部显示设备名称、RouterOS 版本和运行时间。
- 保留所有现有页面、API、终端默认在线筛选、备注编辑和移动端可用性。
- 其他页面沿用参考图的紧凑表格、浅灰表头、细边框、克制阴影和状态标记。

## Acceptance Criteria

- [x] 1440×900 系统概览在模块结构、空间比例、信息密度和组件细节上与参考图明显一致。
- [x] 四张指标卡均有图标、主值和真实辅助信息；任何趋势或分布均能追溯到现有 API 数据。
- [x] 实时流量、系统状态、接口状态、当前告警/健康事件四个区域完整出现。
- [x] 顶栏刷新按钮和刷新周期选择有效，侧栏图标与底部设备信息完整。
- [x] 不显示设备当前不提供的温度、风扇或电源数据，不虚构历史告警。
- [x] 375、768、1024、1440px 下无页面级非预期横向滚动，关键操作可达。
- [x] 所有现有一级页面、终端详情和备注功能无回归。
- [x] 前端 lint/build、Go 测试和真实 RouterOS 浏览器验证通过。

## Out of Scope

- 新增后端监控能力或 RouterOS 配置写入。
- 为匹配参考图伪造数据、告警或硬件传感器。
- 深色主题。
