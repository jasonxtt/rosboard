# iKuai 4.0 设计规范实测记录

来源：登录测试机 http://10.0.0.96（iKuai 4.0.308 免费版）实拍 31 张截图 + getComputedStyle 采样；原始截图在 /tmp/ikuai-live/（临时目录，不持久、不入库）。本文档是持久化的权威记录。

## 配色（computed style 实测值）

| 用途 | 值 |
|---|---|
| 品牌主色（链接、选中文字、主按钮底、tab 下划线） | `#4794EB` |
| 主按钮 hover | `#3A83D4`（推断） |
| 菜单选中背景 | `#F0F9FF`（圆角 8，项高 40） |
| 版本 tag | 底 `#E4EFFC`、字/边 `#4794EB`、圆角 11、12px |
| 表头底 / 表头字 | `#F9F9F9` / `#666`，12px/500，行高 38 |
| 文字梯度 | 主 `#333`（或 rgba(51,51,51,.88)）/ 次 `#666` / 弱 `#999` / 禁用 rgba(51,51,51,.25) |

| 语义色 | 在线/正常绿 `#22C55E`、警告橙 `#F5A623`、错误红 `#D45656` |
| 登录页 | 浅蓝紫极光渐变背景 + 居中白色大圆角卡片 + 浅灰蓝填充输入框 `#EEF2F8` + 全宽实心蓝按钮（高 40、圆角 8） |

## 组件规格

- 主按钮：实心 #4794EB 白字，圆角 6，高 32，padding 0 16
- 次按钮：白底，边框 rgba(0,0,0,.15)，圆角 6，高 32
- 行内操作：蓝色文字链接；删除类红 #D45656
- 页内 tab：激活蓝字 600 + 2px 蓝色下划线
- 分段控件（在线/离线、时间范围）：灰底容器圆角 6，激活块蓝底白字圆角 4
- 表格：无竖线，行间 1px #f0f0f0；上行数值蓝、下行数值绿；底部「共 N 条」+ 分页
- 表单：整页式（非弹窗），label 在上控件在下，必填红 *，控件高约 40
- 空态：灰色插画 +「暂无内容」；未启用功能为营销式空状态
- 右下常驻圆形描边「帮助」悬浮钮（rosboard 无对应功能，不照搬）

## 布局

- 左侧双列导航：一级列 icon+文字，二级列纯文字+小图标（白底，1px 分隔线，二级项紧贴列上沿）；选中一级项浅蓝底圆角
- 一级列顶部：logo + 版本 tag、全局搜索框（⌘K 徽标）
- 无传统顶栏；内容区右上角仅用户图标
- 概览 dashboard：淡彩统计卡（圆环+大数字+细分）+ 图表卡 + 快捷入口 3×3 图标栅格
- 字体栈 PingFang SC / -apple-system 系；正文 13-14px

## 避坑（来自真实用户差评）

- 宽表格需横向滚动时列宽应可调/可配置；信息密度不为美观牺牲太多
- iKuai 4.0 浅色-only；rosboard 保留自有 dark mode
