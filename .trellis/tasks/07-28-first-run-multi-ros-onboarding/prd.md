# 首次安装初始化与多 ROS 设备配置

## Goal

为全新安装提供安全、清晰、可恢复的首次初始化流程：先创建唯一管理员，再按需添加一个或多个 RouterOS 设备。设备只有在连接与核心采集能力验证通过，并完成采集接口和本地 CIDR 配置后才能保存；用户也可以明确跳过设备添加进入空面板。

## Background

- 现有代码已经具备多设备配置、设备切换、归档/恢复和按设备隔离采集数据的基础：`internal/config/config.go:21-41`、`internal/api/server.go:398-589`、`web/src/App.tsx:1159-1246`。
- 现有首次配置页仅在没有 Dashboard 时，依据 RouterOS 是否配置或采集错误显示单个连接表单；它没有独立初始化状态和管理员步骤：`web/src/App.tsx:578-600`、`web/src/App.tsx:941-960`。
- 当前没有登录系统，所有 API 仅受来源 CIDR 限制：`internal/api/server.go:63-74`、`README.md:184-188`。
- 当前新增或编辑设备会直接保存并重启，没有预保存连通性测试，也不要求采集接口或终端 CIDR 非空：`internal/api/server.go:411-438`、`internal/api/server.go:571-589`。
- 当前设置响应会把 RouterOS 密码原文返回浏览器：`internal/api/server.go:206-235`、`internal/api/server.go:264-287`。

## Requirements

### R1. 管理员初始化与账号规则

- 未初始化系统首次打开页面时进入初始化向导，不进入常规登录页或面板。
- 第一步创建系统唯一管理员；首期不支持多个用户或角色。
- 用户名去除首尾空格后必须为 1–64 个字符。
- 密码允许任意字符，不检查大小写、数字、特殊字符等强度组合，长度必须为 4–128 个字符。
- 密码不自动去除首尾空格；创建或修改密码时必须再次输入确认。
- 密码只保存抗暴力破解的哈希，不得明文或可逆保存。
- 管理员创建成功后自动登录并进入 RouterOS 配置步骤。
- 管理员创建后先显示选择页：“添加 RouterOS 设备”或“跳过并进入面板”；只有选择添加后才显示连接输入。
- 并发首个管理员创建请求最多一个成功；创建成功后注册入口立即关闭。

### R2. 登录、会话与账号安全

- 管理员账号用于初始化后的持续认证；未登录用户不能进入面板或访问受保护 API。
- 登录会话有效期为七天，并在持续使用时滚动续期；不提供“记住我”选项。
- 有效会话持久化保存，服务重启不会强制重新登录。
- 退出登录立即作废当前会话。
- “账号安全”使用一个紧凑单列表单同时设置用户名、新密码和确认密码，不要求再次输入当前密码。
- 保存账号和密码后撤销全部会话并返回登录页；退出登录使用与账号表单分离的独立操作区。
- 登录失败按“来源 IP + 规范化用户名”限速；连续五次失败后冷却，继续失败逐步延长。
- 登录成功后清除对应失败计数；不得永久锁定唯一管理员。
- 登录错误不得泄露用户名是否存在。
- 网页不提供无需当前密码的重置入口；程序提供仅服务器本机可执行的交互式 `rosboard admin reset-password` 命令。重置成功后撤销全部会话。

### R3. 初始化状态与路由

- 服务端分别持久化“管理员已创建”和“初始化已完成”状态，不能依赖浏览器状态推断。
- 创建管理员后仍是待完成初始化；只有用户在设备编辑页点击“完成设置”并成功保存当前设备，或在选择页明确点击跳过/进入面板，才标记初始化完成。
- 管理员已创建但第二步未完成时，刷新后继续第二步；会话失效时重新登录后仍返回第二步。
- 页面刷新、关闭、连接失败或保存失败不能产生无法恢复的半初始化状态。
- 跳过后不再返回初始化向导；用户可从面板设备管理入口随时添加设备。

### R4. RouterOS 连接测试

- 初始化向导与初始化后的设备管理使用同一套验证和保存规则。
- 新增设备先填写协议、主机/IP、REST 端口、用户名和密码，再执行连接测试；测试前不显示或启用采集接口和 CIDR 配置。
- 测试凭据在正式保存前不得写入 YAML、SQLite、日志或其他长期存储。
- 成功标准包括：RouterOS REST 认证成功，并能读取系统身份、接口、IPv4/IPv6 地址和核心采集数据。
- 健康、部分 IPv6、队列、策略或路由等可选能力不支持时返回明确警告，但不阻止继续。
- 成功结果包含设备名称、RouterOS 版本、接口、地址、候选 CIDR、可选能力警告和必要诊断信息。
- 修改已通过测试的协议、主机/IP、端口、用户名或密码后，测试结果立即失效。
- 新增设备必须提供有效测试证明；编辑已有设备的任一连接字段时必须重新测试。
- 只修改设备名称、启用状态、采集接口或 CIDR 时无需重新测试，但仍执行完整服务端校验。

### R5. 采集接口、本地 CIDR 与设备保存

- 连接测试成功后才允许进入采集配置阶段。
- 每台设备至少选择一个采集接口，允许选择多个。
- 每台设备至少配置一个本地 CIDR，允许多个 IPv4/IPv6 CIDR。
- 候选来自刚测试的 RouterOS 接口与地址；用户仍需审核，也可手动补充桥接、VLAN 或未直接配置在接口上的本地网段。
- 后端校验接口非空及存在性，并对 CIDR 做语法校验、规范化和去重；前端校验仅用于即时提示。
- 采集接口与 CIDR 均有效，且所选接口具备采集权限后，设备才能写入正式配置。
- 正式 YAML 必须采用原子替换写入；写入失败或进程中断不能留下截断配置，也不能提前标记初始化完成。
- 初始化设备编辑页保留设备列表和新增入口，支持在进入面板前连续添加多台设备。
- 设备编辑页底部并排提供等尺寸、不同实心背景色的“保存设备”和“完成设置”：前者只保存配置、不重启服务并保留初始化状态；后者可直接保存当前尚未单独保存的有效设备、完成初始化、重启服务并进入面板。
- 保留现有设备切换、禁用、归档、恢复和永久删除能力，并全部纳入管理员认证。

### R6. 多设备唯一性

- 以规范化后的协议、主机/IP 和端口作为 RouterOS 目标唯一性。
- 正常、禁用或已归档设备使用相同目标时均拒绝新增；已归档时引导恢复或编辑原设备。
- 设备显示名称允许重复，但列表必须同时显示地址以便区分。
- 不同设备的凭据、采集接口、CIDR、状态和历史数据不能互相覆盖。

### R7. 无设备面板

- 用户跳过 RouterOS 后仍进入完整面板框架。
- 默认页及概览、终端、接口等依赖设备的页面显示统一的“尚未添加设备”空状态和醒目的添加入口，不能卡在加载状态。
- 设备管理、账号安全和退出登录等不依赖采集数据的功能仍可使用。

### R8. 凭据与请求安全

- RouterOS 密码不再通过设置读取接口原文返回；只返回是否已设置。编辑时留空表示保留原密码。
- 管理员密码和 RouterOS 密码不得出现在日志、错误响应、诊断导出或持久化的前端状态中。
- 管理员认证与现有 `allowed_cidrs` 同时生效；CIDR 检查先于初始化、认证和业务处理。
- 全新安装不使用初始化码；只有符合 `allowed_cidrs` 的来源才能创建首个管理员。
- 部署文档必须提示：开放服务前先限制 `allowed_cidrs`，否则不可信网段中的访问者可能抢先注册管理员。

### R9. 完全重新初始化

- 维护设置提供独立的“完全重新初始化”危险操作，不与仅清理当前浏览器偏好的“重置界面偏好”混用。
- 点击后使用一次明确的确定/取消确认，不要求输入确认文字。
- 确认后删除配置文件、唯一管理员、全部会话、初始化状态、所有设备和全部采集历史，并清理本浏览器的 Rosboard 偏好。
- 成功后重启服务并进入首次创建管理员页面；按钮和危险区域使用区别于普通操作的实心警示色。

## Acceptance Criteria

- [x] AC1: 全新安装首次访问只显示管理员创建步骤；简单密码 `1234` 可用，少于 4 个字符、超过 128 个字符、确认不一致或无效用户名会被拒绝。
- [x] AC2: 两个并发管理员创建请求最多一个成功；成功后创建入口关闭并自动建立会话。
- [x] AC3: 管理员创建后刷新仍进入 RouterOS 选择步骤；只有设备编辑页“完成设置”成功保存设备，或选择页明确跳过/进入面板后才完成初始化，单独“保存设备”仍停留在初始化流程。
- [x] AC4: 未认证用户不能读取面板数据、设备设置或凭据，也不能调用变更接口；明确公开的健康、初始化状态和登录接口除外。
- [x] AC5: 登录会话七天滚动续期、跨服务重启有效；退出作废当前会话，改密或本机重置密码作废全部会话。
- [x] AC6: 错误登录触发限速且错误信息不泄露账号存在性；失败请求不能永久锁定管理员。
- [x] AC7: 账号安全按“用户名、密码、再次输入密码、保存”单列显示，不要求当前密码；保存后用户名与密码原子更新、撤销全部会话并返回登录页，退出登录与表单分区显示。
- [x] AC8: 连接失败或缺少核心采集读取权限时不能进入采集设置；可选能力缺失只显示警告。
- [x] AC9: 成功连接测试返回正确设备身份、接口和 CIDR 候选；修改连接字段后原测试证明失效。
- [x] AC10: 新增设备及修改连接字段不能绕过测试；只修改非连接字段无需重复测试。
- [x] AC11: 至少一个有效接口和一个有效 CIDR 才能保存；多接口和混合 IPv4/IPv6 CIDR 可完整保存回读。
- [x] AC12: 无效/重复 CIDR、未知接口、无采集权限接口和重复 RouterOS 目标不能写入正式配置；写入失败或中断不能留下截断 YAML 或错误完成状态。
- [x] AC13: 成功保存一台设备后不重启，初始化页设备列表立即显示已保存设备，并可继续添加设备或点击“完成设置”；填写并验证一台尚未保存的设备后也可直接点击“完成设置”完成保存，完成时只重启一次且恢复后直接显示面板，设备间配置和历史数据保持隔离。
- [x] AC14: 跳过后无设备也能进入完整面板；依赖设备的页面呈现可操作空状态。
- [x] AC15: 设置读取、浏览器状态、错误、日志和导出均不包含管理员密码或 RouterOS 明文密码。
- [x] AC16: 不在 `allowed_cidrs` 内的来源不能创建管理员、登录或访问其他 API。
- [x] AC17: 设备切换、禁用、归档、恢复和永久删除在认证后保持可用。
- [x] AC18: 本机 `rosboard admin reset-password` 可交互式重置密码，不回显或记录明文，并撤销所有会话。
- [x] AC19: “完全重新初始化”经一次确定后清除全部持久化配置、账号、设备和采集数据，重启后进入管理员创建页；取消确认时不产生任何变更，且该操作在视觉和文案上与界面偏好重置明确区分。

## Out of Scope

- 已有版本、已有 YAML 配置或历史 SQLite 数据的升级兼容和迁移。
- 一次性初始化码、邮箱找回密码、外部身份提供商、双因素认证。
- 多管理员、多用户、角色或细粒度权限。
- RouterOS 配置写入；rosboard 仍是只读采集工具。
